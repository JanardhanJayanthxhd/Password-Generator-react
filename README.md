# Password Generator

## Description

A simple password generator that lets you choose a password length and include numbers and special characters. Copy the generated password with one click.

## Tech Stack

- React
- Vite
- Tailwind CSS

## Installation

1. Make sure [Node.js](https://nodejs.org/) is installed.
2. Clone this repository and open the project folder:

   ```bash
   cd password-generator
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal.
